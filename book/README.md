### PDFを作る場合の操作

1. [TechBooster/ReVIEW-Template](https://github.com/TechBooster/ReVIEW-Template)の `articles/` に、v2配下のデータを全てコピー
2. `articles/images/cover.jpg` を追加
3. devcontainerを起動し、 `gem install unicode-display_width`
4. `articles/` で `rake pdf`
